# Customer-controlled completion

The provider may report that work is finished, but this does not close the project.

The project is completed only after the customer uses the secure project dashboard to confirm the provider's completion report. Verified ratings remain locked until that customer confirmation event has been recorded.

Flow:

1. Provider reports work finished.
2. Project remains open and awaits customer confirmation.
3. Customer confirms completion or reports a problem.
4. Customer confirmation closes the project and unlocks verified feedback.
